# My_python_projects

A collection of beginner-friendly Python projects created while learning Python fundamentals, problem-solving, calculations, and basic graphics/simulation.

## Included Projects

### 1. Molarity Calculator
Calculates the molarity of a solution using the number of moles and the solution volume in milliliters.

**Concepts:** `input()`, variables, `float()`, arithmetic operations, `while` loop, `try-except`, conditional statements, and rounding.

**Formula:**

```text
Molarity = moles / volume in liters
```

---

### 2. Phone Number Details
Uses the `phonenumbers` library to parse an international phone number and retrieve information such as location, carrier, timezone, and phone number type.

**Concepts/Tools:** Python functions, dictionaries, exception handling, external libraries, and `phonenumbers`.

---

### 3. Projectile Motion Calculator
Calculates basic projectile-motion quantities from an initial velocity and launch angle.

It calculates:
- Total flight time
- Maximum height
- Horizontal range
- Height at a selected time

**Concepts:** `math` module, trigonometry, functions, variables, `while` loop, input validation, and physics formulas.

---

### 4. Projectile Ball Simulation
A graphical projectile simulation built with `pygame`.

The user can interact with the ball using the mouse to control the launch direction. The program applies gravity to the ball's vertical velocity and updates its position frame by frame. The ball resets when it reaches the ground or moves off the screen.

**Concepts/Tools:** `pygame`, game loop, event handling, mouse input, lists, coordinates, velocity, gravity, collision/reset logic, and real-time animation.

**Required library:**

```bash
pip install pygame
```

---

### 5. Time-Angle Sun-Earth Calculation
Calculates the time represented by a given angular movement based on Earth's 360-degree rotation over 24 hours.

**Concepts:** variables, arithmetic operations, unit conversion, and formatted output.

---

### 6. Turtle Rainbow Flower
Creates a colorful flower-like graphical pattern using Python's `turtle` module and HSV-to-RGB color conversion.

**Concepts/Tools:** `turtle`, `colorsys`, nested `for` loops, colors, angles, circles, and graphical patterns.
